# Darshan M Portfolio

## Build
- Replace the blank page with a polished single-page portfolio and sticky section navigation.
- Create the requested hero, biography, skills, projects, analytics, academics, certifications, resume, contact, and footer sections.
- Use clearly labeled placeholders for missing links, contact details, resume, certificates, dates, and quantified achievements.

## Visual direction
- Use a premium academic-technology aesthetic with deep navy, crisp white, blue-violet accents, subtle glass surfaces, fine grid details, and restrained gradients.
- Pair a confident editorial display face with a highly readable sans-serif body face.
- Build a distinctive animated data-and-technology visual for the opening section plus lightweight project illustrations and analytics charts.
- Keep motion restrained: typing text, section reveals, compact scrolling navigation, hover lift, and reduced-motion support.

## Responsive and accessible behavior
- Prioritize the 390px mobile layout, then expand cleanly for tablet and desktop.
- Provide keyboard-friendly navigation, visible focus states, semantic landmarks, proper labels, descriptive alt text, and accessible menu/filter controls.
- Support dark and light themes, smooth scrolling, lazy-loaded visual assets, and stable layouts without text overlap.

- Implement reusable React section, card, button, navigation, project, and icon patterns using the existing TanStack Start and Tailwind setup.

- Verify the final page in both mobile and desktop viewports and check interaction, console, and build signals.
